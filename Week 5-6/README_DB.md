# Face Recognition System with SQLite3 Database
This repository contains a Face Recognition System built using the face_recognition library for face detection and recognition, with SQLite3 integrated for storing face data (such as user profiles and recognition results). The system can recognize faces from images and webcam feeds, and it stores recognized user information in a local SQLite database for easy management.

## Features
Face detection and recognition from images and live video.

Real-time face recognition using webcam (optional).

SQLite3 database integration to store user data and recognition results.

Supports adding, updating, and deleting user profiles from the database.

Simple and efficient design for small to medium-scale face recognition systems.

## Requirements
Before running the system, ensure you have the following installed:

Python 3.6+

face_recognition library

opencv-python (for image and video processing)

numpy (for numerical operations)

SQLite3 (comes pre-installed with Python, no extra installation needed)
