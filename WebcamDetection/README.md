# Real-Time Face Detection Using Haar Cascades

This project uses OpenCV's Haar Cascade Classifier to perform real-time face detection via a webcam. It highlights detected faces in the video feed with bounding boxes.



## Features
- Detects faces in real-time from the webcam feed.
- Highlights detected faces with blue rectangles.
- Uses OpenCV's pre-trained Haar Cascade Classifier.
