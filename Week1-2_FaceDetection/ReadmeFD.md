# Face Detection

This repository contains two Python scripts for performing face detection using Haarcascade. The scripts demonstrate:
- Real-time face detection using a webcam.
- Face detection from a static image.

Haarcascade is a machine learning-based object detection algorithm that detects faces by analyzing patterns in grayscale images. It can detect single or multiple faces in real-time or from images with high accuracy. The scaleFactor and minimumNeighbors are the main parameters that affect the performance of harcascade.

Features:
- Detects faces using Haarcascade.

Works for:
- Live Camera Input (Webcam).
- Single or Multiple Faces in Images.

Requirements:
- Open CV
